# RadioFiles
JSON files for radios used in the ARCON system of radio control.

See the Wiki for more information about the files, [RSON](https://github.com/guitarpicva/RSON.git) and [ARCON](https://github.com/guitarpicva/ARCON.git).

NOTE: the CODAN.json file works for Envoy and Sentry with FreeTx enabled in the firmware only.  Otherwise, VFO is NOT possible with these radios.  I only included the CODAN file because I own two of them.  May also work for NGT with the same caveat, but is untested.

UBER NOTE!:  CODAN RSON files MUST start with the text 'CODAN' as the front of the filename or they will not be usable.  This is the only exception to the ARCON rule of generic radios only.
